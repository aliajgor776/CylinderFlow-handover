# Native Android/iOS handoff

The current customer surface is responsive/PWA-ready and can be installed from a mobile browser. A signed Android/iOS release requires a native shell (Flutter or Expo/React Native), final API base URL, app identifiers, icons/splash assets, Apple Developer and Google Play accounts, and signing credentials.

The responsive customer routes are deliberately kept API-friendly so the native shell can reuse the same product, cart, order, customer and notification contracts after the server procedures are connected.
